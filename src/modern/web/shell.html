Imperishable Night

Select th08.dat and thbgm.dat from a legally obtained TH08 installation. The game archive is copied only into volatile session memory, while the music archive is range-read from its browser File object. Neither file is uploaded, bundled, or persisted by this page.

Modifier settings, scores, replays, backups, and snapshots use a dedicated browser-storage namespace so they do not overwrite a vanilla TH08 Web profile. Clearing this site's browser data removes them.

Keyboard: arrow keys move, Z confirms/fires, X cancels/bombs, Shift focuses, and Esc pauses.
